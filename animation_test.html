JavaScript Animation Test

ここは、JavaScriptを使ったアニメーションを試すためのページです。
下のボタンを押すと、それぞれ違うアニメーションが始まります。

ヒーローセクションの「ふわふわ図形」

CSSの@keyframesを使って、図形が浮いているように見せるアニメーションです。

ページ背景の「シャボン玉図形」

ページ全体の背景で動いている、下から上へ昇っていくアニメーションです。

Skillsの「きらーん星評価」

マウスを乗せると、スキルレベルに応じて星が光るアニメーションです。JavaScriptで星の数を制御しています。

マウスを乗せてみてにゃん！

ナビゲーションの「ぷるんネコちゃん」

メニューのネコちゃんアイコンにマウスを乗せると、ぷるんと震えるアニメーションです。

hover me!

ローディングの「にゅーっプログレスバー」

ボタンを押すと、ローディング画面のプログレスバーが伸びるアニメーションが再生されます。

ネコちゃんお絵かき

ボタンを押すと、JavaScriptでネコちゃんの顔を描画します。

キラキラ星

ボタンを押すと、JavaScriptでキラキラ光る星をたくさん表示します。
